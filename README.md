# 📊 Foodpanda Sales Performance Dashboard

## Overview

This project analyzes a Foodpanda sales dataset to uncover meaningful business insights using Power BI.

The goal was not just to build a dashboard, but to understand customer purchasing behavior, sales trends, restaurant performance, and payment preferences through interactive visualizations.

---

## Business Questions

This dashboard answers questions such as:

- Which restaurants generate the highest sales?
- How does monthly revenue fluctuate?
- Which cities contribute the most revenue?
- Which payment method is most preferred?
- Which products perform the best?

## Key Insights

- Wallet payments account for the majority of customer transactions.
- Subway recorded the highest sales among all restaurants.
- September achieved the highest monthly revenue.
- Sales distribution varies significantly across cities.
- Fries emerged as the best-selling product.
